---
question: What happens if I remove the microSD card?
lang: en
category: install
order: 11
---
The device starts its original system again, wallet included. As long as NetSluice runs from the card, nothing on the device is changed.

Keep in mind that your network then has no filter. If your router hands out NetSluice as the DNS server, set it back first.

This changes once you install NetSluice to the internal storage. Then the original system is gone unless you put a backup back.
